# Y2K Minecraft Skin

The Y2K Minecraft Skin is a custom texture pack that transforms your Minecraft character into a Y2K-inspired avatar. This skin features a black Y2K shirt, dark jeans, a Spike bracelet, a sleepy face, a thin complexion, brown skin, and straight hair. It's perfect for players who want to add a touch of 2000s nostalgia to their Minecraft experience.

## Install

1. Download the `assets/textures/y2k_skin.svg` file from the project repository.
2. Open your Minecraft game directory.
3. Navigate to the `assets/textures` folder.
4. Replace the existing `skin.svg` file with the downloaded `y2k_skin.svg` file.
5. Launch Minecraft and select the Y2K skin from your character customization options.

## Use

1. Launch Minecraft.
2. Go to the character customization screen.
3. Select the Y2K skin from the available options.
4. Customize your character as desired and start playing.
